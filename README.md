# Portfolio — Vraj Prajapati

Personal portfolio website built with vanilla HTML, CSS, and JavaScript.

🔗 **Live site:** [https://rosander0.github.io/portfolio/](https://rosander0.github.io/portfolio/)

## About

This is my personal portfolio, showcasing my projects, skills, and background as a Computer Engineering student at DJSCE, Mumbai. Built from scratch without frameworks to keep the codebase lightweight and fully understood end to end.

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla, no frameworks)

## Sections

- Home / Intro
- About
- Projects
- Skills
- Contact

## Running Locally

No build step required.

```bash
git clone https://github.com/Rosander0/portfolio.git
cd portfolio
open index.html
```

Or serve it locally with any static server, e.g.:

```bash
npx live-server
```
